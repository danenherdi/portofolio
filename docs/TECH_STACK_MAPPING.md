# Tech Stack Mapping & Categorization

This document maps the specific tools and technologies to their respective domains within the portfolio showcase. Each category represents a professional persona.

## 1. Cloud & DevOps Engineering
*Focus: Scalability, Infrastructure as Code, Automation.*

| Technology | Role / Usage in Portfolio |
| :--- | :--- |
| **Kubernetes (K8s)** | Container Orchestration. Showcase: A live cluster status dashboard or diagram of the portfolio's hosting architecture. |
| **Terraform** | IaC. Snippets showing how the underlying cloud resources (AWS/GCP/DigitalOcean) were provisioned. |
| **Ansible** | Configuration Management. Scripts used for server hardening and setup. |
| **Docker** | Containerization. `Dockerfile` examples for the backend services. |
| **CI/CD (GitHub Actions)** | Automation pipelines. Badges showing build status, test coverage, and deployment history. |

## 2. Backend & Systems Programming
*Focus: Performance, Concurrency, Reliability.*

| Technology | Role / Usage in Portfolio |
| :--- | :--- |
| **Go (Golang)** | High-performance API services. Potential use for a custom analytics microservice. |
| **Rust** | System utilities or WebAssembly (Wasm) modules for heavy computation tasks on the frontend. |
| **Python** | Scripting, Data Analysis, or AI/ML integrations (if applicable). |
| **PostgreSQL** | Primary relational database. Showcase schema design and complex queries. |
| **Redis** | Caching layer. Highlighting performance optimization strategies. |

## 3. Game Development & Quality Assurance
*Focus: Interactivity, Physics, Testing Strategies.*

| Technology | Role / Usage in Portfolio |
| :--- | :--- |
| **Unity / Godot** | Interactive WebGL mini-games or 3D elements embedded in the "Playground" section. |
| **Playwright** | End-to-End (E2E) testing framework. Showcase test scripts for the portfolio itself. |
| **Selenium** | Legacy testing knowledge or comparison case studies. |

## 4. Frontend Ecosystem (The Portfolio Itself)
*   **Framework**: Astro 5 (Performance First).
*   **Interactivity**: Svelte 5 (Reactivity).
*   **Styling**: Tailwind CSS 4 + DaisyUI 5.
*   **State Management**: Nano Stores (Lightweight).
