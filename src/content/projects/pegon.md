Contributed as backend developer in a 6-member team for a client-facing software engineering course project. Built backend services using NestJS and Prisma ORM, supporting core features including manuscript upload, user authentication, bookmarking, and OCR-powered character recognition for Southeast Asian scripts. The application was delivered as a cross-platform PWA supporting both web and mobile access.
